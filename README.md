Tirth Vora | CyberSec Specialist (.onion Theme)

This is a personal portfolio website designed with a Tor Browser / Dark Web aesthetic. It features a simulated browser interface, hacker-themed UI elements, and an AI-powered chatbot.

🚀 Features

Tor Browser UI: Custom CSS simulating the Tor browser window.

Cyber Aesthetic: Glitch effects, neon greens/purples, and terminal fonts.

AI Recruiter Bot: Integrated with Gemini API to answer questions about my skills.

Project Directory: "Hidden Services" grid showcasing my projects with GitHub links.

Skill Arsenal: Visual breakdown of my server admin and security skills.

🛠️ Setup Instructions

Download: Download the index.html file.

Repository: Create a new repository on GitHub (e.g., my-portfolio).

Upload: Upload index.html to the repository.

Deploy: Go to Settings > Pages and set the source to main branch.

Live: Your site will be live at https://yourusername.github.io/my-portfolio.
